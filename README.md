## 🎨 Cómo trabajo

Me gusta adaptar el diseño a lo que necesita cada proyecto y no utilizar siempre el mismo estilo.

Para mí, una buena interfaz tiene que ser:

**Visualmente atractiva** · **cómoda** · **accesible** · **fluida** · **interactiva** · **mantenible**

También intento que las páginas funcionen bien en diferentes dispositivos.

Para ello utilizo cosas como:

`Media Queries` · `Flexbox` · `CSS Grid`

## 🧠 Mi forma de resolver problemas

Cuando me encuentro con un problema que no sé resolver, lo primero que hago es intentar buscar una solución directa.

Si esa solución no funciona, pruebo otra forma de hacerlo.

No siempre tiene que existir una única solución, así que intento buscar una que **funcione bien y tenga sentido** dentro del proyecto.

También intento que la solución quede clara y ordenada, para que otra persona pueda entenderla después.

> **“Si funciona, no lo toques.”**
